# SmartBake Website

Copy the three trained model files into `models/`:
- decision_tree.pkl
- pruned_decision_tree.pkl
- svm.pkl

Install:
`python -m pip install -r requirements.txt`

Run:
`python app.py`

Then open http://127.0.0.1:5000

The website uses the same 10 input features as the SmartBake training pipeline.
